# 🎓 CampusMate Offline

CampusMate is an AI-powered personal study assistant designed to make learning easier and smarter for students. It helps students track their academic progress, upload and organize lecture notes, ask questions using AI, and generate MCQ practice tests from their study materials.

Built using Python, Streamlit, Ollama, Gemma 3:1B, and ChromaDB, CampusMate provides a personalized learning experience with locally running AI.

### Features
- AI-powered study assistant
- Lecture notes upload (PDF and TXT)
- Ask questions from uploaded notes
- Automatic MCQ generation
- Student progress tracking
- Quiz scores and performance analysis
- Dark-themed user interface

### Technologies
Python | Streamlit | Ollama | Gemma 3:1B | ChromaDB

**Goal:** Making student learning smarter, easier, and more organized with AI.
